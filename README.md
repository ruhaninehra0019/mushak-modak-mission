# 🐭 Mushak: The Modak Mission 🪔

A fun and festive **Ganesh Chaturthi adventure game** where you help Mushak collect modaks and reach **Ganpati Bappa** before time runs out!

## 🎮 About the Game

In **Mushak: The Modak Mission**, your goal is to collect all the required modaks while avoiding dangerous obstacles. Use power-ups, manage your lives, and reach the Ganpati idol to complete the mission.

The game includes multiple levels with increasing difficulty.

## 🎯 Objective

* 🥮 Collect all the modaks
* 🐭 Control Mushak through the maze
* 💣 Avoid bombs
* 🧊 Be careful with ice/sliding areas
* 🕳️ Avoid trap holes
* 🌀 Use teleport portals
* ⚡ Use speed boosts
* 🛡️ Use shields
* 🛕 Reach Ganpati Bappa after collecting the required modaks
* ⏱️ Complete the level before the timer reaches zero

## 🕹️ Controls

| Key                  | Action      |
| -------------------- | ----------- |
| ⬆️ Arrow Up / W      | Move Up     |
| ⬇️ Arrow Down / S    | Move Down   |
| ⬅️ Arrow Left / A    | Move Left   |
| ➡️ Arrow Right / D   | Move Right  |
| 📱 On-screen Buttons | Move Mushak |

## ❤️ Lives

The player starts with **3 lives**.

* 💣 Bomb → Lose a life
* 🕳️ Trap → Lose a life
* 🛡️ Shield → Protects the player from obstacles

If all lives are lost, the game ends.

## 🥮 Modaks

Collect the required modaks to progress through the level.

The first level requires **12 modaks**.

## ⚡ Power-Ups & Obstacles

### ⚡ Speed Boost

Helps Mushak move faster.

### 🛡️ Shield

Protects Mushak from certain obstacles.

### 🌀 Portal

Teleports Mushak to another location.

### 🧊 Ice

Makes movement slippery and causes Mushak to slide.

### 💣 Moving Bombs

Moving obstacles that must be avoided carefully.

### 🕳️ Trap Holes

Dangerous areas that can cost a life.

## ⏱️ Timer

Each level has a time limit. Complete the objective before the timer reaches zero.

## 📈 Levels

The game contains multiple levels with increasing difficulty.

### Level 1

* 12 Modaks
* 75 seconds
* Basic obstacles
* Bombs
* Ice
* Trap holes
* Portals
* Speed boost
* Shield
* Ganpati goal


## 🏆 Winning the Game

To complete a level:

**Collect all required modaks → Avoid obstacles → Reach Ganpati Bappa 🛕**

Complete the levels while keeping your lives and time remaining.

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

The game runs directly in a web browser.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the game HTML file.
3. Double-click the HTML file or open it in a web browser.
4. Click **Start Game**.
5. Use the keyboard or on-screen controls to play.
